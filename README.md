# Sails Protocol Website

Official multilingual website for **Sails Protocol: Economic Coordination Protocol for building interoperable P2P financial marketplaces.**

## Stack

- Astro
- Static output
- English, Portuguese and Spanish routes
- Accessible SVG/CSS diagrams and animation
- GitHub as the source of truth

## Development

```bash
npm install
npm run dev
npm run build
```

The website master brief, content governance and implementation roadmap live in [`docs/WEBSITE_MASTER_BRIEF.md`](docs/WEBSITE_MASTER_BRIEF.md).
